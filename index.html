RDP over UDP

TCP freezes. UDP keeps moving.

Over TCP every lost packet stops the screen until it is sent again: a weak Wi-Fi, a VPN or a bad cable is enough to freeze the remote desktop. Over UDP Windows drops what is late and lowers the quality instead, and the desktop keeps moving.

The UDP transport comes from our work in FreeRDP: we found and fixed what made it fail on lossy lines, and it was merged upstream as #13608. Upstream ships it switched off; OpenThinRDP has it on.

Everything a thin client fleet needs

Built for real offices, tills and labs.

🔒

A kiosk, not a desktop

Boots in seconds into a sign-in form with your logo, then full-screen Remote Desktop. No desktop, no menus, no consoles. Clear messages instead of error codes, and it never locks accounts by retrying a wrong password.

⚡

Zero-touch from the domain

A new device needs a domain account and nothing else: it finds its management folder in the domain by itself. Moving the folder later moves the whole fleet in one step.

🔌

USB done right for VDI

Signature keys, tachographs and instruments go to Windows whole. Webcams and headsets work in Teams and Zoom. Smart cards, touch screens, several monitors.

🛡

Signed updates, never in a session

From GitHub or your own folder, installed in the background, applied when the session ends. Pilot devices first, then everyone, and back to an earlier version in one click.

🩺

Health Center for the Windows side

Brokers, Hyper-V hosts and cluster, VMs, domain controllers, DNS, SQL AlwaysOn and backups in one tree, each problem in a plain sentence with its fix.

💻

Any hardware you already own

Old office PCs and used thin clients, UEFI with Secure Boot or legacy BIOS, the complete Debian 13 kernel and firmware. Cable, Wi-Fi, 802.1X, VPN and RD Gateway.

Up and running

From USB stick to Windows desktop in five minutes.

  1. 1

    Download and boot

    Write the ISO to a USB stick and boot any PC from it. The live system never writes to the disk.

  2. 2

    Sign in

    Set the broker (or a Windows PC) and the domain, and sign in to your desktop. That's the test.

  3. 3

    Install and manage

    Like it? Choose Install, about three minutes. Then name the folder in the domain and every new device sets itself up.
