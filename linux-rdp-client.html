Remote Desktop from Linux to Windows: FreeRDP, Remmina or a thin client OS

To open a Windows desktop from a Linux computer there are three ways. They share the same engine, FreeRDP; what changes is how much is done for you.

On a Linux PC you use for other things too, Remmina is the simple choice. On a computer that should only open Windows, a desktop with Remmina has to be locked down and kept up to date by hand; that is what OpenThinRDP does for you (the alternatives).

Why is Remote Desktop slow from Linux?

The most common causes, in order:

  1. TCP on a line that loses packets (Wi-Fi, VPN, a busy link). Windows' own client switches to UDP; Linux clients based on a released FreeRDP stay on TCP, and TCP stops at every lost packet. With UDP, on a line losing 50% of its packets we measured 19-21 frames per second, where TCP was down to 0.6 at 20% (measurements).
  2. Graphics mode: without the GFX pipeline (/gfx) the screen is sent as plain bitmaps. OpenThinRDP uses it by default, with the progressive codec that keeps text sharp on servers without a GPU (RDP_GFX).
  3. The packaging: a Flatpak or Snap of Remmina can be slower than the native package on some systems.
  4. The server: a busy session host or VM is slow from any client; the manager's health check shows it.

Can I connect to Windows Home?

No: Windows Home can connect to others but cannot be connected to with Remote Desktop, from any client. Windows Pro, Enterprise, Education and Windows Server can (Settings > System > Remote Desktop). A Windows virtual machine on Hyper-V, Proxmox or VMware usually runs Pro or Server and can. Upgrading Home to Pro is done from Settings > System > Activation.

Two monitors, sound, webcam, USB

With OpenThinRDP:

  • Several monitors become one Windows desktop across all of them.
  • Sound and microphone through the RDP audio channels; webcams through the RDP camera channel, seen by Teams, Zoom and the browser in the session.
  • USB sticks appear in Windows as drives; signature keys and special devices are passed whole; smart card readers through the smart card channel.
  • Printers: a network printer is used by Windows directly; a USB printer can be passed whole to Windows.
